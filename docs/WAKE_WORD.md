# 🗣️ Своё слово активации «Джарвис»

Слово активации обеспечивает демон
**[station-wakeword](https://github.com/tangenx/station-wakeword)** (автор —
[tangenx](https://github.com/tangenx)). Он слушает тот же поток, что и штатный
споттер (`yio_audio`, канал `vqe_0` — уже после эхоподавления и шумодава), и,
услышав слово, просит Алису начать слушать — как будто нажали кнопку.

Прошивка не меняется. «Алиса» продолжает работать как обычно.

## Что устанавливается

| Что | Где |
| --- | --- |
| демон (статический бинарник) | `/data/wakeword/wakeword` |
| набор «не-слов» (~17 МБ) | `/data/wakeword/negatives.bin` |
| автозапуск | `/etc/init.d/S97wakeword` |
| ваши слова и настройки | `/data/wakeword/` |
| веб-интерфейс | `http://<IP-колонки>:8780` |
| лог | `/tmp/wakeword.log` |

Скачайте бинарник и `negatives.bin` со страницы релизов проекта
`station-wakeword` и разложите:

```powershell
adb shell "mkdir -p /data/wakeword"
adb push wakeword      /data/wakeword/wakeword
adb push negatives.bin /data/wakeword/negatives.bin
adb shell "chmod 755 /data/wakeword/wakeword"
```

Автозапуск (файл `S97wakeword` из релиза):

```powershell
adb push S97wakeword /data/wakeword/S97wakeword
adb shell "mount -o remount,rw /"
adb shell "cp /data/wakeword/S97wakeword /etc/init.d/S97wakeword; chmod 755 /etc/init.d/S97wakeword; sync; mount -o remount,ro /"
adb shell "/etc/init.d/S97wakeword start"
```

Проверка:

```powershell
adb shell "/etc/init.d/S97wakeword status; pidof wakeword; tail -5 /tmp/wakeword.log"
```

## Шаг 1. Открыть интерфейс

В браузере на ПК или телефоне (в той же Wi-Fi сети):

```
http://192.168.1.50:8780
```

Сверху — индикатор микрофона. Полоска должна шевелиться от разговора. Если
стоит на месте — колонка не отдаёт звук, проверьте `channel` в настройках.

## Шаг 2. Записать фон комнаты (8 секунд)

«Добавить слово» → имя `джарвис` → записать 8 секунд тишины. Не выключайте
холодильник и не выгоняйте домашних: пусть фон будет настоящий — с
телевизором и улицей.

## Шаг 3. Записать само слово — 10–15 раз

Нажимаете «Записать», ждёте «Говорите!», один раз говорите **«Джарвис»**.
Каждую запись можно прослушать и удалить неудачную.

Как записывать, чтобы работало:

- **с разных мест** комнаты — вплотную к колонке, с дивана, из кухни;
- **разной громкостью** — обычно, тихо, громко;
- **разными голосами** — если колонкой пользуются несколько человек, пусть
  запишут все: модель учится на всех записях сразу;
- не кричите и не растягивайте — говорите так, как будете говорить в жизни.

Минимум 6 удачных записей, оптимум 10–15.

## Шаг 4. (Необязательно) Обычная речь — 20 секунд

Кнопка «Обычная речь»: читаете с экрана текст 20 секунд обычным голосом.
Станция запомнит, как звучит ваша нормальная речь, и реже будет путать её со
словом. Занимает полминуты, заметно снижает ложные срабатывания.

## Шаг 5. Обучить

Кнопка «Обучить». Обучение идёт **на самой станции**, 2–3 минуты, занимает
~67 МБ памяти. В это время колонка тормозит — это нормально, ничего не
выключайте. В конце покажет recall (доля пойманных записей) и оценку ложных
срабатываний в час.

## Шаг 6. Проверить

Скажите: **«Джарвис…»** — пауза — **«который час»**.

Важно: после слова нужна короткая пауза (полсекунды). Демон просит Алису
начать слушать именно в момент слова, поэтому «Джарвисвключисвет» слитно не
сработает. Правильно: «Джарвис… включи свет».

В интерфейсе полоска уверенности должна доходить до отметки, а в «Последних
срабатываниях» появится запись — её можно прослушать.

## Настройка чувствительности

У каждого слова есть ползунок «реже ↔ чаще»:

- слово не ловится → двигайте к «чаще»;
- срабатывает на телевизор и разговоры → к «реже».

Если станция откликнулась зря, в «Последних срабатываниях» нажмите
**«Ложное»**: запись попадёт в обучение как пример «не-слова», и после
«Переобучить» таких ошибок станет меньше.

## Настройки в файле

`/data/wakeword/settings.json` — править **при остановленном демоне**:

| Ключ | Смысл | По умолчанию |
| --- | --- | --- |
| `channel` | канал `yio_audio` | `vqe_0` |
| `gain` | усиление (канал очень тихий) | `32` |
| `dry_run` | только показывать срабатывания, не будить Алису | `false` |
| `words.<id>.enabled` | включено ли слово | — |
| `words.<id>.sensitivity` | чувствительность | — |

## Ресурсы

- память: ~5 МБ в покое, до ~80 МБ на время обучения;
- процессор: ~16 % одного ядра при активном слове;
- `/data`: 24 МБ (бинарник + negatives).

## Если что-то сломалось

**После обновления прошивки (OTA)** пропадает `/etc/init.d/S97wakeword`
(rootfs перезаписывается). Лечится одной командой:

```powershell
adb push S97wakeword /data/wakeword/S97wakeword
adb shell "mount -o remount,rw /; cp /data/wakeword/S97wakeword /etc/init.d/S97wakeword; chmod 755 /etc/init.d/S97wakeword; sync; mount -o remount,ro /; /etc/init.d/S97wakeword start"
```

Сами записи и модели в `/data/wakeword/` при OTA не пропадают.

**Демон не стартует** — смотрите `/tmp/wakeword.log`. Частая причина: порт
8780 занят вторым экземпляром (`pidof wakeword` покажет два процесса).

**Удалить совсем:**

```powershell
adb shell "/etc/init.d/S97wakeword stop"
adb shell "mount -o remount,rw /; rm -f /etc/init.d/S97wakeword; sync; mount -o remount,ro /"
adb shell "rm -rf /data/wakeword"
```
