# 🤝 Как помочь проекту

Спасибо, что заглянули! Проект живёт на энтузиазме, и любая помощь — код,
документация, тесты на другой прошивке или просто хороший баг-репорт — ценна.

## 🐞 Сообщить об ошибке

Откройте [issue](../../issues) и приложите:

1. **Что вы делали** — пошагово, вплоть до произнесённой фразы.
2. **Что ожидали** и **что получилось**.
3. **Версии**: прошивка колонки, версия quasar-bridge, модель LLM.
4. **Логи** (без секретов!):

```powershell
adb -s <IP>:5555 shell "tail -50 /data/opt/quasar-bridge/bridge.log"
adb -s <IP>:5555 shell "tail -5 /data/opt/quasar-bridge/conversations.jsonl"
adb -s <IP>:5555 shell "wget -q -O - http://127.0.0.1:8443/healthz"
```

5. **Что уже пробовали** — чтобы мы не повторяли ваши шаги.

⚠️ Перед публикацией логов удалите IP, ключи, тексты личных разговоров.

## 💡 Предложить идею

Создайте issue с меткой `enhancement` и ответьте на три вопроса:

- какую задачу это решает;
- как это должно выглядеть для пользователя;
- не ломает ли это работу без ПК.

## 🔧 Pull request

1. Форкните репозиторий и создайте ветку:
   ```bash
   git checkout -b feature/korotkoe-nazvanie
   ```
2. Держите изменения **узкими**: один PR — одна задача.
3. Соблюдайте стиль окружающего кода:
   - **PowerShell** — `Verb-Noun`, параметры с дефолтами, `$ErrorActionPreference = "Stop"`;
   - **JavaScript** — ES-модули, без внешних зависимостей в воркере;
   - **Go** — `gofmt`, без CGO;
   - **Python** — 3.10+, `from __future__ import annotations`, без «магии».
4. Проверьте, что:
   - `config.example.json` — валидный JSON;
   - скрипты не содержат личных IP, ключей и путей;
   - документация обновлена, если менялось поведение.
5. В описании PR укажите: что изменено, зачем, как проверяли.
6. Коммиты — в повелительном наклонении, по-русски или по-английски:
   `fix: не сбрасывать маршрут при пустом ASR`.

## 🧪 Чек-лист перед отправкой

- [ ] `config.example.json` парсится (`python -c "import json;json.load(open(...))"`).
- [ ] В диффе нет `.env`, `config.json`, `runtime.env`, ключей и логов.
- [ ] `healthz` после изменений отвечает `"status":"ok"`.
- [ ] Голосовая проверка: «Джарвис, кто ты» → ответ LLM; «выключи свет» → Яндекс.
- [ ] Откат (`apply_endpoint.ps1 -Rollback`) по-прежнему работает.
